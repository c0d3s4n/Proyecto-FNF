# Reap3r Crew — base de canciones para Freeplay

Este directorio es un mod inicial para Psych Engine 0.2.8.

## Instalación
1. Copia la carpeta `Reap3rCrew` dentro de la carpeta `mods` de tu juego compilado.
2. Abre el juego y entra en Freeplay. Las siete canciones aparecerán como entradas seleccionables.
3. Los JSON de `data/` son charts de prueba mínimos, no charts finales.

## Pendiente
- Añadir el instrumental `Inst.ogg` a `songs/<slug>/` para cada tema.
- Añadir `Voices.ogg` solo si la canción necesita voces separadas.
- Crear charts reales, personajes, escenarios, iconos y eventos cuando desarrollemos las ideas.
- Las carpetas de audio tienen un `.gitkeep` porque Git no conserva carpetas vacías.

No se han descargado ni incluido los clips de Kick; quedan como referencias creativas fuera de los archivos del juego.
